# D2F Hub for the Night Owl AFC

Sensored Hub for use with the AFC Klipper add-on, using a D2F switch and a 5.5mm ball bearing.

## Assembly

### Bill of Materials

- 1x D2F Switch
- 1x 5.5mm ball bearing ball
- 2x M2x10mm Self-Tapping Screw
